## 📦 Install

**One command (installs the whole collection):**

```bash
curl -fsSL https://raw.githubusercontent.com/milad-ahmd/agent-skills/main/install.sh | bash -s -- brand-voice-guide
```

**Manually (Claude Code):**

```bash
git clone https://github.com/milad-ahmd/brand-voice-guide /tmp/brand-voice-guide
mkdir -p ~/.claude/skills && cp -r /tmp/brand-voice-guide/skills/brand-voice-guide ~/.claude/skills/
```

**Per project:** copy `skills/brand-voice-guide` into `<project>/.claude/skills/`.
**Any other agent:** paste [`SKILL.md`](skills/brand-voice-guide/SKILL.md) into your rules or system prompt.

## 💬 Usage

Just ask your agent:

```text
Create a brand voice guide from our website
Make this post sound like our brand
```

The full workflow, rules and output format are in [`SKILL.md`](skills/brand-voice-guide/SKILL.md).
